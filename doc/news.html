Latest News and Releases

TR-4 released
Posted on June 6, 2010
The fourth technical release includes not only a complete review of the systems programming module (Pt-System) and the networking module (Pt-Net), but also two new modules: Pt-Http and Pt-XmlRpc. The logging facilities have been integrated into the Pt-System module and the text handling classes have been inegrated into the Pt core module. This leads to reduced binary size and fewer shared libraries. At least the following modules will be part of the 1.0 release: Pt (core), Pt-System, Pt-Net, Pt-Unit, Pt-Xml.
TR-3 released
Posted on February 15, 2008
Starting with this TR, the Pt core module is in a soft-freeze, thus source compatibility should not be broken except in case of critical bugs. Changes and additions can still be made of course, if they do not break sorce compatibility. New features include support for Solaris, and OS-X. The GUI module for Mac OS-X uses the Objective-C Cocoa API's, though it is not yet complete.
TR-2 released
Posted on October 16, 2007
The second technical release adds support for async I/O and I/O multiplexing on all available I/O devices, atomic operations for integers and pointers, a logging framework, date and time classes, a new module for reflection and updates to the Unit testing framework. AIX unix is supported now and Pt has been shown to compile and run successfully on symbian based operating systems.
New Project Website
Posted on February 25, 2007
The new project website integrates the generated doxygen documentation into the project pages. The online reference documentation was improved and contains class groups for easier navigation.
TR-1 released
Posted on February 5, 2007
This slightly longer development sprint has lead to the TR-1 release. Many improvements have been made to the core module and the Gfx module. A new module for network programming was added (%Pt::Net). Pt can now be built wit the intel compiler on win32. The code is available as a tarball in the download section or as a tag in the subversion repository (tags/tr1).
Development News
Posted on February 5, 2007
During the last month, enhancements have been made to the Gfx module and the core module, Most notably to the image classes and the reflection API. A new module for unit testing was added. Pt::Unit allows protocol- and data-driven testing.
Pt and Tntnet at LinuxWorldExpo in Cologne
Posted on October 14, 2006
Platinum was presented together with Tntnet, the open-source web application server, at LinuxWorldExpo in Cologne in the open source pavillion.
Pt on Sourceforge
Posted on September 22, 2006
The Platinum C++ framework is now hosted on sourceforge.net. The source code is available through an SVN repository and generated documentation can be viewed online now.
