TR-4 released
Posted on June 6, 2010
The fourth technical release includes not only a complete review of the systems programming module (Pt-System) and the networking module (Pt-Net), but also two new modules: Pt-Http and Pt-XmlRpc. The logging facilities have been integrated into the Pt-System module and the text handling classes have been inegrated into the Pt core module. This leads to reduced binary size and fewer shared libraries. At least the following modules will be part of the 1.0 release: Pt (core), Pt-System, Pt-Net, Pt-Unit, Pt-Xml.

TR-3 released
Posted on February 15, 2008
Starting with this TR, the Pt core module is in a soft-freeze, thus source compatibility should not be broken except in case of critical bugs. Changes and additions can still be made of course, if they do not break sorce compatibility. New features include support for Solaris, and OS-X. The GUI module for Mac OS-X uses the Objective-C Cocoa API's, though it is not yet complete.

TR-2 released
Posted on October 16, 2007
The second technical release adds support for async I/O and I/O multiplexing on all available I/O devices, atomic operations for integers and pointers, a logging framework, date and time classes, a new module for reflection and updates to the Unit testing framework. AIX unix is supported now and Pt has been shown to compile and run successfully on symbian based operating systems.

The Power in your Hands

Platinum is a comprehensive C++ framework, that allows developers to write high-performance applications for many platforms with only one codebase. It provides a large amount of features and is still remarkably easy to use. It intergrates well into existing toolkits and frameworks.

...unleash the power of Pt today!

A consistent API for advanced object modeling, multithreading, synchronous and asynchronous I/O, file-system access, system programming, plugins, networking, database access, graphics, XML processing and graphical user interfaces is provided on all supported platforms.

Pt can be used on embedded devices, desktops or large servers. The supported platforms include Windows, Windows CE, Linux, QNX, and Unix. It lets you spend your time on your application without tedious low-level programming.

A high degree of performance is achieved through the use of modern C++ features. Programs will benefit from the many optimizations included in the framework.

Pt is designed from the ground up to be flexible and extensible. It provides simple solutions to your problems without being intrusive. It integrates well with existing code bases or other toolkits and frameworks. Programs written with Pt tend to be significantly shorter and much easier to understand.

Its not just open, its free! Published under the LGPL it allows you to write commercial and open-source applications and be part of the great community that develops Pt and determines its future.
